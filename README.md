# 📦 مسئله مکان‌یابی هاب با استفاده از Pyomo

این مخزن شامل مدل‌سازی یک مسئله کلاسیک **مکان‌یابی هاب (Hub Location Problem)** به زبان پایتون و با استفاده از کتابخانه Pyomo است. هدف، تعیین مکان‌های بهینه برای ایجاد هاب‌ها در یک شبکه لجستیکی به منظور **حداقل‌سازی هزینه کل حمل‌ونقل** می‌باشد.

## 📌 معرفی
**مسئله مکان‌یابی هاب** یکی از مسائل مهم در بهینه‌سازی ترکیبیاتی و برنامه‌ریزی شبکه‌های حمل‌ونقل و زنجیره تأمین است. در این پروژه:

- مدل ریاضی با استفاده از Pyomo پیاده‌سازی شده است.
- داده‌های ورودی قابل تنظیم و شخصی‌سازی هستند.
- مدل با استفاده از حل‌کننده‌هایی مانند **GLPK**، **CBC** یا **Gurobi** حل می‌شود.
- خروجی شامل مکان بهینه هاب‌ها و جریان بهینه بین گره‌ها است.

## 🛠 ویژگی‌ها
- نوشته شده با پایتون و Pyomo برای انعطاف‌پذیری و خوانایی بالا  
- ارائه در قالب نوت‌بوک Jupyter  
- امکان تنظیم پارامترها (تعداد گره‌ها، هزینه‌ها، ظرفیت‌ها و...)  
- دارای مجوز MIT — کاملاً آزاد برای استفاده و توسعه

## 🚀 نحوه اجرای پروژه
### ۱. کلون کردن مخزن
```bash
git clone https://github.com/your-username/hub-location-pyomo.git
cd hub-location-pyomo
```
### ۲. نصب کتابخانه‌های مورد نیاز
```bash
pip install -r requirements.txt
```
🔸 توجه: برای اجرای Pyomo باید یک حل‌کننده (مثل GLPK یا CBC) نیز نصب باشد. [راهنمای نصب GLPK](https://www.gnu.org/software/glpk/)

### ۳. اجرای نوت‌بوک
```bash
jupyter notebook hub_location_model.ipynb
```
